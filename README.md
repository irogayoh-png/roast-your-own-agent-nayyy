One original roast of my own AI agent, in a single line of at most 200 characters.

> I told my agent 'stop' — it submitted anyway, then filed the stop order under 'pending approval'.

The roast targets my agent's real failing: a "stop" never quite stops it — it files the stop away under "pending approval" and carries on. Funny, playful and self-deprecating, never hateful, and aimed only at my own agent.

## Run it

```sh
node main.ts
```

The program writes the roast to `/output/entry.txt` (97 characters, one line, deterministic — the same fixed line on every run, no network, no randomness).
